# مصروفي

وكيل صغير يسجّل مصاريفك من كلامك العادي، بنموذج دربته بنفسك في كولاب ويشتغل على جهازك بدون إنترنت.

```
أنت: تغديت ب٤٠ أمس وعبيت بنزين ب٨٠
سجلت:
  ✓ غدا: 40 ريال · مطاعم · أمس
  ✓ بنزين: 80 ريال · مواصلات · اليوم
```

## المتطلبات
- Python 3.10 أو أحدث (ما يحتاج أي مكتبة إضافية)
- [Ollama](https://ollama.com/download)
- حساب Google لتشغيل الدفتر في كولاب

## الخطوات
1. افتح `masrufi_colab.ipynb` في Google Colab، واختر **T4 GPU**، وشغّل الخلايا بالترتيب.
2. نزّل من Google Drive الملفين `masrufi.Q4_K_M.gguf` و `Modelfile` وحطهم في هذا المجلد.
3. في الطرفية داخل المجلد:

```
ollama create masrufi -f Modelfile
ollama pull qwen3:1.7b
python eval.py qwen3:1.7b masrufi
python agent.py
```

## الملفات
| الملف | وش يسوي |
|---|---|
| `make_data.py` | يولّد بيانات التدريب والاختبار، وفيه تعليمات النظام والتصنيفات |
| `masrufi_colab.ipynb` | دفتر التدريب في كولاب: قبل، تدريب، بعد، تصدير |
| `Modelfile` | يعرّف النموذج في Ollama بنفس قالب المحادثة اللي تدرّب عليه |
| `llm.py` | يكلّم Ollama ويطلّع الـ JSON ويتحقق منه (الحواجز) |
| `agent.py` | الوكيل: يسجّل في `expenses.csv` ويعطيك ملخص |
| `eval.py` | يقيس أي نموذج على رسائل الاختبار |

## الحواجز اللي في الكود
- أي رد مو JSON صالح ما يتسجّل.
- المبلغ لازم يكون أكبر من صفر وأقل من ٥٠ ألف.
- التصنيف لازم يكون من القائمة، وإلا يصير «أخرى».
- أي مبلغ فوق ١٠٠٠ ريال يطلب تأكيدك قبل التسجيل.
- بياناتك في `expenses.csv` على جهازك، ما تطلع لأي مكان.
